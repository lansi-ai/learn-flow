# 练习与反馈设计指南（practice-guide.md）

## 01. 核心命题：没有反馈的练习，是重复犯错

学习效果的差别，90% 不在学习时长，在**有没有反馈回路**。

```
无反馈：做 → 以为自己做对了 → 重复 100 次 → 固化错误
有反馈：做 → 立刻知道哪错了 → 下一次改一处 → 真的进步
```

所以练习库不是「题集」，是**反馈装置**。设计练习时，第一问题不是「练什么」，是「**练完怎么知道对不对**」。

---

## 02. 练习四段式（每个练习文件必须含这四段）

```markdown
# <练习名>

## 1. 目标行为
做完这个练习，我能独立做到：<具体行为>

## 2. 操作步骤
1. <可执行步骤>
2. ……

## 3. 自检标准
- [ ] <可打勾的判定项>
- [ ] <可打勾的判定项>
- 达标线：<几项通过算过>

## 4. 我的结果与差距
- 完成日期：
- 实际产出：<文件 / 链接>
- 自检结果：<过了几项，哪项没过>
- 差距分析：<为什么没过，下次改哪一处>
```

第 3 段和第 4 段是绝大多数人省略的，也恰恰是唯一产生学习效果的部分。

---

## 03. 自检标准怎么写

**唯一要求：能判定。** 自己看完能立刻回答「过 / 没过」，不能有解释空间。

| ❌ 不可判定 | ✅ 可判定 |
|---|---|
| 写得自然流畅 | 通读一遍，没有需要回读才懂的句子 |
| 开头有吸引力 | 给 3 个同事看，至少 2 个愿意看下去 |
| 剪辑节奏好 | 无单镜头超过 4 秒；全片无静音段超过 1.5 秒 |
| 理解了这个概念 | 关掉资料，用 100 字讲给外行，对方能复述出 2 个要点 |
| 代码质量高 | 有异常处理；函数 ≤ 50 行；跑通 3 个边界用例 |

**技巧**：把标准写成「**操作 + 阈值**」。没有阈值就问自己「差到什么程度算失败」，那个点就是阈值。

**另一种技巧：对照法。** 拿一个公认的好样本，逐条对比差异。适合审美类、表达类这种难量化的能力：

> 把我的版本和样本并排，逐段标出：我少做了什么、多做了什么、顺序不同在哪。

## 04. 三种反馈来源（优先级从高到低）

| 层级 | 来源 | 速度 | 可信度 | 适用 |
|---|---|---|---|---|
| **外部客观反馈** | 平台数据（播放/完播/转化）、考试成绩、真实用户反馈 | 慢（小时~天） | 最高 | 有发布渠道的一切 |
| **外部主观反馈** | 老师、同行、目标读者给的意见 | 中 | 高（但会客套） | 表达、审美、专业判断 |
| **自我对照反馈** | 自检清单、与样本对比、闭卷复述 | 快（秒级） | 中（易自欺） | 所有场景的兜底 |

设计原则：**能拿到外部反馈的，绝不用自我反馈兜底。**

问用户的三句话：

1. 「这个东西做出来，能给谁看？他凭什么要给你真实意见？」
2. 「有没有一个数字能反映它好不好？（播放、通过率、返工次数）」
3. 「如果没人可问也没数据可看，你的自检清单是哪几条？」

第 3 问是兜底——**大多数时候只有第 3 问有答案**，所以自检清单必须写得足够硬。

**防客套话**：向人求反馈时，不问「你觉得怎么样」，要问：

- 「哪一段你想跳过？」（比「哪里好」有效 10 倍）
- 「如果只能删一部分，你删哪？」
- 「你看完记住了什么？」（测真实留存）

## 05. 练习数量与分布

**宁少勿多。** 首月 10–15 个，覆盖全部能力域。

理由很直接：建 50 个练习的心理效果是「我有 50 个要练，压力好大，先刷会儿手机」，建 12 个的效果是「今天练第 3 个」。

分布建议：

| 能力域状态 | 练习数量 | 说明 |
|---|---|---|
| 掌握度 0–1（新手） | 3–4 个 | 从最小可完成单元开始，先建立「我能做出来」的感觉 |
| 掌握度 2（能复述） | 2–3 个 | 重点是脱稿：去掉模板再做一次 |
| 掌握度 3（能独立做） | 1–2 个 | 变式练习：换个场景 / 换个约束再做一次 |
| 掌握度 4（能教） | 0–1 个 | 讲给别人听，收集对方的困惑点 |

**递进设计**：同一单元的练习要有梯度——`照着做 → 半脱稿 → 全脱稿 → 换场景`。四步走完才算真的会。

## 06. 反馈回路的时间设计

| 能力类型 | 反馈窗口 | 原因 |
|---|---|---|
| 发布类内容 | 24–72 小时 | 平台流量集中在发布后 24h，过了数据就失真 |
| 交付类作品 | 交付时 / 评审时 | 错过评审窗口就没有真实意见了 |
| 应试类 | 做完立刻 | 延迟对答案会把错误记忆强化 |
| 审美/表达类 | 24 小时内找人看 | 拖久了对方没印象，只能给客套话 |

**回填纪律**：到窗口没回填，任务置 `blocked` 并写明卡在哪。

---

## 07. 卡点处理

连续两次练习没进展，不要继续练第三次——**换方式，不换强度**。

三步：

1. **降维**：把任务拆到更小。写不出脚本 → 先只写开头一句。
2. **换路径**：看别人怎么做的（拆解一个样本），而不是继续自己硬想。
3. **问人**：把具体卡点（不是「我不会」）说清楚去问。「我这个开头前 3 秒是抛问题，但完播率只有 20%，是不是问题类型选错了？」

**卡点必须记录**：写进 `docs/reviews/pitfalls.md`，四段式（现象/根因/正解/复发信号）。同一个坑第二次踩，说明当时没记或没看。
