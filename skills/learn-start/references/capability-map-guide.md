# 能力地图指南（capability-map-guide.md）

## 01. 能力地图是什么

能力地图 = **把「会做某件事」拆成若干个可以单独练、单独验收的单元**。

它不是课程目录。课程目录按「知识章节」组织（第 1 章、第 2 章），能力地图按「能力」组织（能选题、能写钩子、能剪节奏）。区别在于：**章节学完不知道会不会，能力单元练完知道会不会**。

结构只有三层，不要更多：

```
能力域（4–6 个）
└── 单元（每个域 2–5 个）
    └── 任务（由 learn-task 在看板里产生）
```

超过 6 个能力域，说明还没抓住主线——回到阶段 1 重问终点。

---

## 02. 能力域的拆法

### 两种拆法，按目标性质选

**拆法 A：按流水线环节（适合有明确产出的技能）**

适用于自媒体、设计、编程、写作——凡是「从想法到交付」有固定环节的。

例：自媒体运营 → 选题力 / 脚本力 / 表达力 / 制作力 / 数据力 / 账号力

好处：和实际工作顺序一致，练完就能串起来用。
风险：容易漏掉「贯穿性能力」（如审美、网感），需要单独补一域。

**拆法 B：按能力层次（适合知识型 / 应试型目标）**

例：备考 → 基础概念 / 题型识别 / 解题速度 / 抗压稳定

好处：对应试很准，直接映射到分数来源。
风险：容易变成章节搬运，要克制。

### 每个能力域必须写三项

| 项 | 说明 | 不合格 |
|---|---|---|
| **这个域解决什么** | 一句话，说清缺它会怎样 | 「提升综合能力」 |
| **判断达标的信号** | 外部可观察的现象 | 「感觉更熟练了」 |
| **当前掌握度** | 0–4，附证据或标明「无证据」 | 直接给 3 分不给理由 |

## 03. 单元的粒度

**判定标准只有一条：能不能在 1–3 次练习内做完，并当场验收。**

- 太大：「学会写脚本」→ 拆成「写出一个 15 秒钩子」「设计一个三幕结构」「把术语翻译成人话」
- 太小：「记住 5 个术语」→ 合并进「能用行话说清一个概念」
- 刚好：「拆解 10 条同垂类爆款，归纳出 3 个可复用的钩子模板」

单元四要素（缺一不可）：

```markdown
### <单元编号> <单元名>
- 练什么：<具体动作，可执行>
- 怎么算练会：<可判定的标准，能打勾或打分>
- 产出什么：<文件 / 作品 / 一段录音，可展示>
- 当前掌握度：<0–4>（证据：<有 / 无>）
```

「怎么算练会」的写法对照：

| ❌ 不合格 | ✅ 合格 |
|---|---|
| 理解钩子的作用 | 能写出 5 个开头，其中至少 3 个让同事愿意看完 |
| 掌握剪辑节奏 | 把一段 60 秒素材剪到 30 秒，信息不丢，无空镜超 1 秒 |
| 熟悉 Excel 函数 | 不看搜索，用 3 个函数解决给定的 5 道题，全对 |

## 04. 掌握度五级（与 LEARN-RULES 一致）

| 级别 | 名称 | 判定证据 |
|---|---|---|
| 0 | 未接触 | 无 |
| 1 | 能认 | 看得懂术语和别人的成品，但自己做不出来 |
| 2 | 能复述 | **不看材料**能说清关键要点与逻辑 |
| 3 | 能独立做 | 无模板、无教程，独立产出合格品 |
| 4 | 能教别人 | 能讲清为什么这样做，能指出别人的错误并纠正 |

评级纪律：

- **没证据最高记 1。** 用户说「我会」，但拿不出东西 → 记 1，注明「待补证据」。
- **跟着教程做过 ≠ 3 级**，只能算 2 级（能复述 + 能模仿）。
- **4 级不是荣誉称号**，是「能给别人改错」的实用能力，别乱给。
- 掌握度会**降**。复习答不出就降 1 级，这是机制不是失败。

## 05. 优先级怎么排

不要按「哪个容易先做」排，按两条：

1. **瓶颈优先**：哪个域卡住整条链路，先补哪个。选题不行，脚本写得再好也没人看。
2. **可验证优先**：哪个域能最快拿到外部反馈，先做哪个。有反馈的练习进步速度是没有反馈的 3 倍以上。

写成表格放进计划：

| 能力域 | 优先级 | 理由 | 首月是否动 |
|---|---|---|---|
| 选题力 | P0 | 决定内容生死，且最快能拿到数据反馈 | 是 |
| 脚本力 | P0 | 直接决定完播率 | 是 |
| 数据力 | P1 | 需要先有内容才能练，首月只做基础口径 | 部分 |
| 制作力 | P2 | 可用模板兜底，不阻塞发布 | 否 |

## 06. 计划文件模板

```markdown
# 能力地图 — <目标名>

> 能力终点：<可验证行为>
> 时间预算：每周 <N> 小时（已按七折折算）
> 更新日期：<YYYY-MM-DD>

## 不做清单
- <明确砍掉的方向 1>：理由
- <明确砍掉的方向 2>：理由

## 能力域总览
| 域 | 解决什么 | 达标信号 | 当前掌握度 | 优先级 |
|---|---|---|---|---|

## 01 <能力域名>
### 01-1 <单元名>
- 练什么：
- 怎么算练会：
- 产出什么：
- 当前掌握度：

## 里程碑
| 时间 | 交付物 | 验收方式 |
|---|---|---|
| 第 4 周 | | |
```

**行数预算**：单域计划 ≤ 120 行；整份 ≤ 400 行。超了先砍单元，不要加文件。
